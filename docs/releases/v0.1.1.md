# Draconium v0.1.1

Patch release for **Draconium** — hardening window IPC/navigation isolation, token entropy, `file://` symlink containment, and smoother window resizing on top of `v0.1.0`.

[日本語リリースノート / Japanese Release Notes](#japanese)

---

## Changes Since v0.1.0

- **Smooth window resizing (`draconium-host`)**:
  - Deduplicated redundant `WindowEvent::Resized` notifications and ignored zero-size minimized resizes.
  - Triggered immediate compositor sync (`spin_event_loop`, `webview.paint`, and `rendering_context.present`) inside `WindowEvent::Resized` for cleaner live drag-resizing on Windows.
- **Origin confinement & `file://` symlink containment**:
  - Enforced strict initial-origin confinement (`allows_navigation_for_origin_with_fs`) across main and child windows, preload script execution, and async script replies (`resolve_async_script_for_origin`).
  - Added canonicalized directory containment for `file://` apps (`resolve_initial_file_dir`, `try_resolve_app_url_from`), non-UTF-8 Unix path support, Unicode lowercase parity on Windows, implicit `:80` default port matching in `DevOrigin`, and `@` handling in HTTP query/fragment components.
- **Per-window async IPC & child window isolation**:
  - Routed async `PendingAsyncTask`, `PendingCapture`, and `PendingSessionOp` callbacks strictly to the originating `target_window: WindowId` rather than broadcasting.
  - Gave each child window an isolated `UserContentManager` (`child_ucm`) and guaranteed async error settlement when `spawn_child_window` fails early.
  - Validated `devtools_addr` loopback binding in `run()` and replaced panicking `rustls` crypto provider install with non-panicking `let _ = ...`.
- **CSPRNG token entropy & protocol hardening (`PR #7`)**:
  - Sourced launch session tokens and Win32 file-access tokens from OS CSPRNG with fail-closed behavior and capped `register_batch_json` at `MAX_CAPABILITY_TOKENS` (64).
  - Added `.xml` / `.xhtml` / `.xht` MIME types and strict `Content-Security-Policy` headers for `dn://app/` XML/HTML/SVG responses.
- **Input, reload & shutdown fixes (`PR #2`)**:
  - Fixed input key/cursor mapping, added configurable `HostConfig::with_reload_shortcuts`, and bounded graceful `WM_CLOSE` shutdown timeout.

## Download & Run (Windows x64)

1. Download `draconium-v0.1.1-windows-x64.zip` and `SHA256SUMS.txt`.
2. Verify the archive checksum:

```powershell
Get-FileHash .\draconium-v0.1.1-windows-x64.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

3. Extract the zip archive and launch Folio or Starter:

```powershell
.\draconium.exe --workspace --dn-assets
.\draconium.exe --starter --dn-assets
```

# Draconium v0.1.1（日本語）

`v0.1.0` に対するパッチリリースです。ウィンドウリサイズ時の再描画平滑化に加え、オリジン・`file://` シンボリックリンク封じ込め、子ウィンドウ非同期 IPC 分離、トークン乱数強度、入力／終了制御の修正を反映しています。

## v0.1.0 からの主な変更点

- **ウィンドウリサイズ描画の平滑化（`draconium-host`）**:
  - `WindowEvent::Resized` の重複・ゼロサイズ（最小化時）通知を抑止し、サイズ変更直後に `spin_event_loop`・`webview.paint`・`rendering_context.present` を即時同期してドラッグリサイズ時のちらつきを軽減しました。
- **オリジン封じ込め・`file://` シンボリックリンク検証の強化**:
  - 初期オリジン検証（`allows_navigation_for_origin_with_fs`）をメイン／子ウィンドウのナビゲーション、プリロード JS、非同期応答（`resolve_async_script_for_origin`）へ一貫適用しました。
  - `file://` 起動時の正規化ディレクトリ境界検証（`resolve_initial_file_dir` / `try_resolve_app_url_from`）、非 UTF-8 Unix パス対応、Windows 大文字小文字比較、`DevOrigin` の既定ポート `:80` 補完、HTTP クエリ／フラグメント内 `@` 許可、ループバック限定 `devtools_addr` 検証、`.xml`/`.xhtml`/`.xht` MIME＋CSP 付与を追加しました。
- **子ウィンドウ分離と非同期 IPC ルーティング**:
  - `PendingAsyncTask`・`PendingCapture`・`PendingSessionOp` を対象 `WindowId` へ厳密ルーティングし、子ウィンドウごとに `UserContentManager` を分離、`spawn_child_window` 早期失敗時の非同期エラー返却を保証しました。
- **トークン CSPRNG 化と権限上限（PR #7）**:
  - セッショントークン／ファイルアクセストークンを OS CSPRNG から生成（失敗時フェイルクローズ）し、`register_batch_json` を 64 件上限に制限しました。
- **入力・リロード・終了処理修正（PR #2）**:
  - キー／カーソルマッピング修正、`HostConfig::with_reload_shortcuts` 追加、`WM_CLOSE` タイムアウト制御を反映しました。

## ダウンロードと実行（Windows x64）

1. `draconium-v0.1.1-windows-x64.zip` と `SHA256SUMS.txt` をダウンロードします。
2. SHA-256 ハッシュを検証します：

```powershell
Get-FileHash .\draconium-v0.1.1-windows-x64.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

3. ZIP を展開し、Folio または Starter を起動します：

```powershell
.\draconium.exe --workspace --dn-assets
.\draconium.exe --starter --dn-assets
```
