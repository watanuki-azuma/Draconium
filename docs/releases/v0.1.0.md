# Draconium v0.1.0

First public preview release of **Draconium** — a lightweight, self-contained Rust desktop WebView host powered by **Servo 0.8.0** (Stylo 0.23, WebRender 0.70, SpiderMonkey), requiring no Chromium bundle or OS WebView runtime.

[日本語リリースノート / Japanese Release Notes](#japanese)

---

## Highlights

- **Reusable `draconium-host` crate API**: Builder-based Rust embedding API (`HostConfig`, `WindowConfig`, `HostHandler`, `Capabilities`, `EmbeddedAsset`, `run`) decoupled from showcase UI assets.
- **Capability-gated `window.Draconium` bridge**: Per-launch 128-bit session-token authentication, recursively `Object.freeze`'d preload API, and automatic privilege attenuation for child windows (`openChild` / `window.open`).
- **Custom `dn://app/` protocol + CSP**: Path-traversal protection, compiled-in `EmbeddedAsset` (`include_bytes!`) single-binary fallback, strict `Content-Security-Policy` headers (with optional `--csp-wasm`), and navigation lock to `dn://app/`, local `file://`, `about:blank`, and optional loopback `--dev-url`.
- **Custom chrome & window lifecycle**: Frameless transparent rounded shell (`drag`, 8-edge `dragResize`, minimize, maximize, F11 fullscreen, layered opacity, always-on-top, system tray `--tray`, global hotkeys `--hotkey`, and single-instance `WM_COPYDATA` forwarding).
- **Native desktop integration**: Native file/folder pickers and save dialogs, capability-scoped drag-and-drop (`dn:file-drop`), rich clipboard (`text`, `HTML`, `CF_DIB` images), DPAPI `safeStorage`, desktop notifications, `HKCU` autostart, and system Light/Dark theme sync.
- **Export, diagnostics & rendering**: Built-in raster PDF / HTML / PNG export, structured `.crash.json` crash reports, loopback Firefox DevTools RDP (`--devtools`), and GPU CSS `backdrop-filter` support (`HostConfig::with_backdrop_filter`, enabled by default).
- **Optional `media-gstreamer` feature**: Compile-time opt-in Cargo feature for GStreamer 1.20+ audio/video playback (`DummyBackend` by default with zero external media DLLs).

## Included Showcase Applications

The single self-contained `draconium.exe` (~112 MiB) includes three modes:

- `--workspace` *(default)* — **Folio**: Local-first Markdown workspace with custom frameless chrome, Write / Split / Preview modes, atomic `.md` persistence, drag-and-drop file import, native HTML/PDF/PNG export, and an on-demand 60-frame Render Lab.
- `--starter` — **Starter**: Minimal developer template demonstrating `HostHandler`, `Draconium.invoke` / `invokeAsync`, and OS theme synchronization.
- `--probe` — **Comparison Probe**: Shared `ui/index.html` harness for benchmarking Draconium (Servo 0.8.0) against WebView2.

## Download & Run (Windows x64)

1. Download `draconium-v0.1.0-windows-x64.zip` (~112 MiB self-contained binary + UI assets + `LICENSE`) and `SHA256SUMS.txt`.
2. Verify the archive checksum:

```powershell
Get-FileHash .\draconium-v0.1.0-windows-x64.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

3. Extract the zip archive and launch Folio or Starter:

```powershell
.\draconium.exe --workspace --dn-assets
.\draconium.exe --starter --dn-assets
```

## Known Limitations

- **Windows x64 binaries only**: This release attaches portable Windows x64 binaries only.
- **macOS & Linux status**: Pure-Rust `std` OS backends compile and pass CI checks on Ubuntu and macOS, but prebuilt binaries are not yet attached and live desktop GUI validation remains pending.
- **Unsigned executable**: `draconium.exe` is currently unsigned, so Windows SmartScreen may show an unrecognized app warning on first launch.
- **Media disabled in default build**: Built without `media-gstreamer` (`DummyBackend`), so HTML5 `<audio>` / `<video>` playback is inactive in this binary.
- **Preload isolation boundary**: The `window.Draconium` preload bridge runs in the page realm rather than an isolated context (`contextBridge` parity depends on upstream Servo support).

# Draconium v0.1.0（日本語）

**Draconium** の初回パブリックプレビューリリースです。Chromium のバンドルや OS 標準 WebView ランタイムに依存せず、**Servo 0.8.0**（Stylo 0.23 / WebRender 0.70 / SpiderMonkey）を単一バイナリへ内蔵した軽量 Rust デスクトップ WebView ホストを提供します。

## 主なハイライト

- **再利用可能な `draconium-host` クレート API**: ビルダー形式の Rust 組み込み API（`HostConfig` / `WindowConfig` / `HostHandler` / `Capabilities` / `EmbeddedAsset` / `run`）を UI アセットから分離して提供。
- **権限境界付き `window.Draconium` ブリッジ**: 起動ごとの 128-bit セッショントークン認証、再帰的 `Object.freeze` による改ざん防止、子ウィンドウ（`openChild` / `window.open`）への自動権限減衰を実装。
- **`dn://app/` カスタムスキーム＋厳格 CSP**: ディレクトリトラバーサル防止、`EmbeddedAsset`（`include_bytes!`）単一バイナリフォールバック、`Content-Security-Policy`（`--csp-wasm` 選択可）、および遷移先制限（`dn://app/`・ローカル `file://`・`about:blank`・`--dev-url` ループバック）。
- **カスタムクロームとウィンドウ制御**: 透過角丸フレームレスウィンドウ（`drag` / 8方向 `dragResize` / 最小化・最大化 / F11 フルスクリーン / ウィンドウ透過率 / 最前面固定 / `--tray` / `--hotkey` / `--single-instance` `WM_COPYDATA` 引数転送）。
- **ネイティブデスクトップ統合**: ファイル・フォルダ選択／保存ダイアログ、ケーパビリティ制御付きドラッグ＆ドロップ（`dn:file-drop`）、リッチクリップボード（Text / HTML / `CF_DIB` 画像）、DPAPI `safeStorage`、デスクトップ通知、`HKCU` 自動起動、OS ライト／ダークテーマ同期。
- **出力・診断・描画機能**: ラスタ PDF / HTML / PNG エクスポート、構造化 `.crash.json` クラッシュレポート、ループバック Firefox DevTools RDP（`--devtools`）、GPU CSS `backdrop-filter`（`HostConfig::with_backdrop_filter`、既定有効）。
- **任意の `media-gstreamer` 機能**: GStreamer 1.20 以降を用いた音声／動画再生の Cargo feature に対応（標準ビルドは外部 DLL 不要の `DummyBackend`）。

## 同梱アプリケーション

単一実行ファイル `draconium.exe`（約 112 MiB）に 3 つのモードを同梱しています：

- `--workspace` *(既定)* — **Folio**: 透過角丸クローム・Write / Split / Preview 切替・`.md` アトミック保存・D&D 取込・HTML / PDF / PNG エクスポート・60fps Render Lab を備えたローカル Markdown ワークスペース。
- `--starter` — **Starter**: `HostHandler`・`Draconium.invoke` / `invokeAsync`・テーマ同期の基本を確認できる最小開発テンプレート。
- `--probe` — **比較プローブ**: WebView2 と同一条件で比較計測するための共通画面（`ui/index.html`）。

## 既知の制限事項

- **Windows x64 バイナリのみ配布**: 本リリースで添付している実行バイナリは Windows x64 版のみです。
- **macOS / Linux ビルド**: Rust `std` ベースの OS バックエンドは Ubuntu / macOS の CI チェックを通過していますが、配布バイナリの添付および実機デスクトップでの GUI 検証は未実施です。
- **未署名バイナリ**: `draconium.exe` にはコード署名を付与していないため、初回起動時に Windows SmartScreen の警告が表示される場合があります。
- **標準ビルドではメディア無効**: 本バイナリは `media-gstreamer` 無効（`DummyBackend`）でビルドしているため、`<audio>` / `<video>` の再生には対応していません。
- **プリロード JS の隔離境界**: `window.Draconium` はページと同一 JS レルムに注入されます（独立レルムによる `contextBridge` 相当の隔離は上流 Servo の対応待ち）。
